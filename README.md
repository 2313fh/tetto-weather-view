# 鉄塔気象ビュー

送電鉄塔の位置に合わせて、気象庁のオープンデータをスマートフォンで見るためのページです。
GitHub Pages でそのまま動きます（サーバー・APIキー不要）。

## できること

- **いまの実況** … 最寄りアメダス観測点の雨・風・気温、鉄塔20km圏内の落雷数（LIDEN）
- **雨の予測** … 降水短時間予報＋降水15時間予報を重ねて、最長15時間先まで1時間ごとに表示
- **中止目安の先読み** … 「1回の降雨量」を予報から積算し、基準に達する見込み時刻を表示
- **全鉄塔サマリ** … この先の雨が強い順・落雷検知・中止見込みの鉄塔を一覧
- 10分ごとに自動更新（ページを開いている間）

## 使い方

1. このリポジトリの GitHub Pages URL をスマホで開く
2. 「鉄塔データを読み込む」で、Excel マクロ（鉄塔気象予測_Ver自動.xlsm の「スマホ用書き出し」）で作った JSON ファイルを選ぶ
3. 以後はページを開くだけ。ホーム画面に追加するとアプリのように使えます

## 鉄塔データの扱い

**鉄塔の座標データはこのリポジトリには含まれていません。**
読み込んだデータはブラウザの端末内ストレージ（localStorage）にだけ保存され、外部には送信されません。

### データ形式

```json
{
  "v": 1,
  "lines": [
    { "name": "線路名", "towers": [ { "no": 1, "lat": 33.123456, "lon": 130.123456 } ] }
  ]
}
```

## 出典・注意

- 出典: [気象庁ホームページ](https://www.jma.go.jp/bosai/)（公共データ利用規約 第1.0版に基づく利用）
- 気象庁が API として保証している配信ではないため、予告なく形式が変わり表示できなくなる可能性があります
- 風・気温・WBGT の数値予報、落雷の予報は気象庁の無料公開に含まれないため、このページの予測は雨のみです
- 表示される値は目安です。作業可否の判断は現場の計測と社内規程に従ってください

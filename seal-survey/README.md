# 展示アンケート集約（電子シール アンケート Ver.2）

展示会の電子シール式アンケートを、複数人で集約するためのページです。
GitHub Pages でそのまま動きます（サーバー・APIキー不要、HTML 1ファイル完結）。

公開URL：https://2313fh.github.io/tetto-weather-view/seal-survey/

## できること

- 最初に「入力者名・会社名・日付」を入れて開始 → ID（例：`20261116-7K3QXM`）を発行し、入力者ごとに端末内へ別々に保存
- 保存一覧から再開（絞り込み・バックアップ・削除）
- 同じデータを同じ端末の別タブ・別画面で同時に入力できないようにロック（引き継ぎ可）
- 同じ入力者・同じ日付のデータを作ろうとすると警告（二重計上の防止）
- 別の端末のバックアップを「データを取り込む」で集約（同じIDは重複させず、新しい方を残す）
- 「合算を見る」で複数人の票を合計（読み取り専用）、全件CSV（ID・入力者・会社名・入力日の列つき）
- iPhone・iPad のタップ操作に対応。一度開けば電波が弱い会場でも再読み込みできます（Service Worker）

## データの扱い

票数・入力者名・会社名は、各端末のブラウザー内（localStorage）と、利用者が保存したバックアップ・CSVにだけ記録されます。外部へは送信しません。端末どうしの自動同期はありません。

## ファイル

- `index.html` … アプリ本体（CSS・JavaScript込みの1ファイル。旧版のバックアップJSONも読み込めます）
- `sw.js` … オフライン用（このフォルダのページだけをキャッシュし、他のページには影響しません）

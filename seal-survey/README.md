# 展示アンケート集約（スプレッドシート登録版）

全員の入力を、代表者のGoogleスプレッドシート（共有サーバー）に自動で集める版です。

- 公開URL：https://2313fh.github.io/tetto-weather-view/seal-survey/
- スタッフは、代表者から届く「共有リンク」（`?sync=…` 付き）を各端末で1回開くだけで接続されます
- スマホだけで完結させる版（JSONで集約）：https://2313fh.github.io/tetto-weather-view/seal-survey-local/

## できること

- 最初に「入力者名・会社名・日付」を入れて開始 → ID（例：`20261116-7K3QXM`）を発行し、入力者ごとに保存
- 入力のたびに端末へ自動保存し、数秒ごとにまとめて共有サーバーへ自動送信（電波がないときは自動で再送）
- 代表者は「全員分を見る」から、全員分の合算・CSV・バックアップを一括で取り出し
- 共有サーバーは入力者ごと（ID単位）に1行。同じIDは新しい内容で上書きされ、重複しません
- 同じデータを2つの画面で同時に入力できないようにロック（引き継ぎ可）、同じ入力者・同じ日付の重複警告
- 共有サーバーに未接続の端末では、画面上部に警告を表示

## 共有サーバー（代表者が1回だけ設定）

1. https://script.google.com で「新しいプロジェクト」を作り、`Code.gs` の内容を貼り付けて保存
2. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」／実行ユーザー「自分」／アクセス「全員」→ デプロイ → 承認
3. 表示されたウェブアプリのURL（…/exec）を、アプリの「共有サーバーを設定」に貼り付けて「接続」
4. 「共有リンクを送る」で、入力する人にリンクを送る

データは代表者のGoogleドライブの「展示アンケート集約データ」に保存されます。集計から外す行は「除外」列に入力します。

## データの扱い

票数・入力者名・会社名は、各端末のブラウザー内と、共有サーバー（代表者のGoogleスプレッドシート）に記録されます。それ以外の外部送信はありません。共有リンクを知っている人は全員分を読み書きできるため、関係者以外に共有しないでください。

## ファイル

- `index.html` … アプリ本体（CSS・JavaScript込みの1ファイル）
- `Code.gs` … 共有サーバー用の Google Apps Script
- `sw.js` … オフライン用（このフォルダのページだけをキャッシュ）

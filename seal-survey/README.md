# 展示アンケート集約（スプレッドシート登録版）

入力すると、集計担当のGoogleスプレッドシートに自動で集まる版です。

- 公開URL：https://2313fh.github.io/tetto-weather-view/seal-survey/
- スタッフは、集計担当から届く共有リンク（`?sync=…` 付き）を各端末で1回開けば接続されます
- スマホだけで完結させる版：https://2313fh.github.io/tetto-weather-view/seal-survey-local/

## できること

- 名前・会社名・日付を入れて開始すると、入力者ごとにID（例：`20261116-7K3QXM`）で保存
- 入力はその都度端末に保存し、まとめてスプレッドシートへ送信（電波がないときは後で自動送信）
- 集計担当は「全員分を見る」から、全員分の合算・CSV・バックアップを出せる
- スプレッドシートは1人1行（ID単位）。同じIDは新しい内容で上書きされ、重複しません
- ①をタップした時刻で来場時間帯も記録。「集計」で1時間ごとの来場者数（1日目・2日目、最初・最後・ピーク）、CSVは「時間帯別」も出せる

## 共有サーバー（集計担当が1回だけ設定）

1. https://script.google.com で新しいプロジェクトを作り、`Code.gs` を貼り付けて保存
2. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」／実行ユーザー「自分」／アクセス「全員」→ デプロイ
3. 表示されたURL（…/exec）を、アプリの「共有サーバーの設定」に貼って「接続」
4. 「共有リンクを送る」で全員に送る

集計から外す行は、スプレッドシートの「除外」列に何か入力します。共有リンクは関係者以外に送らないでください。

## ファイル

- `index.html` … アプリ本体（1ファイル）
- `Code.gs` … 共有サーバー用の Google Apps Script
- `sw.js` … オフライン用

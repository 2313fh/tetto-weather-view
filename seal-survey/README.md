# 展示アンケート集約（電子シール アンケート Ver.2）

展示会の電子シール式アンケートを、複数人で集約するためのページです。
GitHub Pages でそのまま動きます（HTML 1ファイル完結）。

公開URL：https://2313fh.github.io/tetto-weather-view/seal-survey/

## できること

- 最初に「入力者名・会社名・日付」を入れて開始 → ID（例：`20261116-7K3QXM`）を発行し、入力者ごとに保存
- 保存一覧から再開（絞り込み・バックアップ・削除）
- 同じデータを同じ端末の別タブ・別画面で同時に入力できないようにロック（引き継ぎ可）
- 同じ入力者・同じ日付のデータを作ろうとすると警告（二重計上の防止）
- **共有サーバー（Googleスプレッドシート）**：全員の入力を自動で1か所に集約。代表者は「全員分を見る」から合算・CSV・バックアップを一括で取り出せます
- 共有サーバーを使わない場合も、バックアップの「データを取り込む」で集約できます（同じIDは重複させず、新しい方を残す）
- iPhone・iPad のタップ操作に対応。一度開けば電波が弱い会場でも再読み込みでき、未送信分はつながったときに自動で再送します

## 共有サーバーの設定（代表者が1回だけ）

1. https://script.google.com で「新しいプロジェクト」を作り、`Code.gs` の内容を貼り付けて保存
2. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」／実行ユーザー「自分」／アクセス「全員」→ デプロイ → 承認
3. 表示されたウェブアプリのURL（…/exec）を、アプリの「共有サーバーを設定」に貼り付けて「接続」
4. 「共有リンクを送る」で、入力する人にリンクを送る（各端末で1回開けば接続されます）

データは代表者のGoogleドライブに自動で作られる「展示アンケート集約データ」に、入力者ごと（ID単位）に1行で保存されます。集計から外す行は「除外」列に入力します。

## データの扱い

票数・入力者名・会社名は、各端末のブラウザー内（localStorage）と、利用者が保存したバックアップ・CSVに記録されます。共有サーバーに接続した場合だけ、代表者のGoogleスプレッドシートへ送信します（それ以外の外部送信はありません）。共有リンクを知っている人は全員分を読み書きできるため、関係者以外に共有しないでください。

## ファイル

- `index.html` … アプリ本体（CSS・JavaScript込みの1ファイル。旧版のバックアップJSONも読み込めます）
- `Code.gs` … 共有サーバー用の Google Apps Script（アプリ内の「スクリプトをコピー」と同じ内容）
- `sw.js` … オフライン用（このフォルダのページだけをキャッシュし、他のページには影響しません）

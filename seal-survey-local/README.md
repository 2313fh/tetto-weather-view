# 展示アンケート集約（スマホ完結版）

データを各端末の中だけに保存し、全員分はファイルを集めて合算する版です。外部には送信しません。

- 公開URL：https://2313fh.github.io/tetto-weather-view/seal-survey-local/
- スプレッドシートに自動で集める版：https://2313fh.github.io/tetto-weather-view/seal-survey/

## できること

- 名前・会社名・日付を入れて開始すると、入力者ごとにID（例：`20261116-7K3QXM`）で端末に保存
- 保存一覧から再開・バックアップ・削除
- ①をタップした時刻で来場時間帯も記録。「集計」で1時間ごとの来場者数（1日目・2日目、最初・最後・ピーク）、CSVは「時間帯別」も出せる

## 全員分の集め方

1. 各自：「全件バックアップ」→「共有して保存」で、ファイルを集計担当へ送る
2. 集計担当：「データを取り込む」で受け取ったファイルをまとめて選ぶ（同じデータは重複しません）
3. 「合算を見る」で全員分の合計、「全件CSV」でExcel用のファイル

iPhone・iPadは、しばらく開かないとデータが消えることがあります。毎日送ってください。

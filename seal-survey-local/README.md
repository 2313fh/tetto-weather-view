# 展示アンケート集約（スマホ完結版）

各端末の中だけで保存し、全員分はバックアップ（JSON）を集めて取り込む版です。外部へは送信しません。

- 公開URL：https://2313fh.github.io/tetto-weather-view/seal-survey-local/
- 共有サーバーで自動集約する版：https://2313fh.github.io/tetto-weather-view/seal-survey/

## できること

- 最初に「入力者名・会社名・日付」を入れて開始 → ID（例：`20261116-7K3QXM`）を発行し、入力者ごとに端末内へ保存
- 保存一覧から再開（絞り込み・バックアップ・削除）
- 同じデータを2つの画面で同時に入力できないようにロック（引き継ぎ可）、同じ入力者・同じ日付の重複警告

## 全員分の集め方

1. 各自：保存一覧の「全件バックアップ」でJSONファイルを保存し、AirDrop・LINE・メールで集める人に送る
2. 集める人：「データを取り込む」で受け取ったファイルをまとめて選ぶ（複数可）
3. 「合算を見る」で全員分の合計、「全件CSV」でExcel用の一覧（ID・入力者・会社名・入力日の列つき）

同じIDのデータは重複せず、新しい方に置き換わります。バックアップはスプレッドシート登録版にも取り込めます。

## データの扱い

保存先は各端末のブラウザー内（localStorage）だけです。iPhone・iPadでは、しばらく開かないとサイトのデータが消えることがあるため、毎日の終わりにバックアップを保存してください。

## ファイル

- `index.html` … アプリ本体（CSS・JavaScript込みの1ファイル）
- `sw.js` … オフライン用（このフォルダのページだけをキャッシュ）
